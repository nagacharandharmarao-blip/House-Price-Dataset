# House Price Dataset
This repository contains a comprehensive dataset of house prices along with various features that influence property valuations. It is designed for exploratory data analysis (EDA), data visualization, and building predictive machine learning models for real estate valuation.

## 📊 Dataset Overview

The dataset includes structural, geographical, and economic features of residential properties. It can be used to solve regression problems (e.g., predicting the exact price of a house) or classification problems (e.g., categorizing houses into price ranges).

### Key Features
* **Price:** The sale price of the property (Target Variable).
* **Bedrooms:** Number of bedrooms in the house.
* **Bathrooms:** Number of bathrooms.
* **Square Footage:** Total living area in square feet.
* **Lot Size:** Total property area size.
* **Location/Neighborhood:** Geographic identifier or neighborhood tier.
* **Year Built:** The year the property was originally constructed.

## 🛠️ Project Goals & Use Cases

* **Predictive Modeling:** Train linear regression, decision trees, or ensemble models (like XGBoost) to predict property values.
* **Feature Engineering:** Analyze the impact of location vs. square footage on house prices.
* **Data Visualization:** Create heatmaps and scatter plots to discover market trends and pricing corridors.
